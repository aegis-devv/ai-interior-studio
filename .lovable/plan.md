# Atelier Verve Interior Studio

## Goal
Build an original, high-impact interior design website inspired by the reference site’s clear studio structure, using the selected Frosted Editorial Luxe direction.

## What will be built
- A cinematic home page with oversized editorial typography, sculptural imagery, frosted overlays, and subtle architectural light effects.
- A responsive navigation menu linking to dedicated Work, Philosophy, Journal, and Contact pages.
- An asymmetric project showcase using the five custom interior images already generated.
- A concise studio philosophy, design process, selected-project details, and a strong consultation call to action.
- Fully responsive mobile layouts, accessible controls, reduced-motion support, and optimized image loading.

## Pages
- **Home:** Studio statement, featured project, selected work, design approach, and consultation prompt.
- **Work:** Curated project gallery and project summaries.
- **Philosophy:** Studio principles, materials, process, and credibility.
- **Journal:** Editorial stories and design observations.
- **Contact:** Project inquiry form and studio contact details.

## Visual direction
- Fraunces display type with Manrope body type.
- Warm ivory, graphite, pale stone, and brushed brass palette.
- Asymmetric magazine layouts, curved architectural image crops, restrained frosted surfaces, and fine-line details.
- Slow image reveals, moving coordinate strip, tactile hover motion, and a full-screen mobile menu.

## Technical details
- Use the existing TanStack Start structure and semantic design tokens.
- Create separate routes with unique metadata for every main page.
- Keep all imagery bundled locally and all controls keyboard accessible.
- Validate desktop and mobile rendering in the live preview.
